# Metrology Helper

Приложение-калькулятор для перевода единиц измерения различных физических величин.

## Реализованная функциональность (Версия 1.0)

### Конвертер длины
- Поддерживаемые единицы измерения:
  - **Метрические**: метр (м), дециметр (дм), сантиметр (см), миллиметр (мм), километр (км)
  - **Имперские**: фут (ft), дюйм (in), ярд (yd), миля (mi)
  - **Морские**: морская миля (nmi)
  - **Астрономические**: световой год (ly), астрономическая единица (AU)

### Основные возможности
- Ввод значения в любую единицу измерения с автоматическим пересчетом во все остальные
- Визуальное выделение единицы СИ (метр) с помощью цветного фона и метки "Единица СИ"
- Группировка единиц по категориям для удобной навигации
- Поддержка больших и малых чисел в экспоненциальной форме (научная нотация)
- Автоматическое сохранение состояния конвертера
- Кнопка "Сброс" для очистки всех полей
- Кнопка "Информация" у каждой единицы измерения (функционал будет добавлен позже)

### Технические особенности
- Material Design 3 интерфейс
- Поддержка темной и светлой темы
- Navigation Drawer для переключения между конвертерами
- RecyclerView для эффективного отображения списка единиц
- SharedPreferences для сохранения состояния
- Unit-тесты для проверки математической логики

## Технический стек
- Java
- Android SDK (минимальная версия: API 26, Android 8.0)
- Material Components 3
- RecyclerView
