### Реализованная функциональность

#### 1. Конвертер единиц длины
Создан полностью функциональный конвертер для перевода единиц измерения длины между различными системами измерения.

**Поддерживаемые единицы (12 шт.):**

| Категория | Единицы |
|-----------|---------|
| Метрические | метр (м), дециметр (дм), сантиметр (см), миллиметр (мм), километр (км) |
| Имперские | фут (ft), дюйм (in), ярд (yd), миля (mi) |
| Морские | морская миля (nmi) |
| Астрономические | световой год (ly), астрономическая единица (AU) |

#### 2. Визуальное выделение единицы СИ
- Метр выделен цветным фоном (#FFF3E0 для светлой темы, #2E2416 для темной)
- Добавлена цветная рамка (#FF9800 для светлой темы, #B96420 для темной)
- Отображается метка "Единица СИ" под названием единицы

#### 3. Пользовательский интерфейс
- **Material Design 3** компоненты
- **Navigation Drawer** для переключения между конвертерами
- **Группировка по категориям** с отдельными заголовками
- **Кнопка "Сброс"** в верхней панели для очистки всех полей
- **Кнопка "Информация"** у каждой единицы (функционал будет добавлен позже)
- **Поддержка темной темы** с адаптивными цветами

#### 4. Функциональные возможности
- ✅ Ввод значения в любое поле
- ✅ Автоматический пересчет во все остальные единицы
- ✅ Поддержка больших и малых чисел в экспоненциальной форме (1.5E+10, 3.2E-5)
- ✅ Автоматическое сохранение состояния при выходе из приложения
- ✅ Восстановление состояния при запуске
- ✅ Точность вычислений до 10 знаков после запятой

#### 5. Архитектура и код
**Классы:**
- `LengthUnit` - модель единицы измерения
- `LengthUnits` - справочник всех единиц с коэффициентами перевода
- `LengthConverter` - математическая логика конвертации
- `ConverterState` - состояние конвертера (текущие значения)
- `ConverterPreferences` - сохранение/загрузка через SharedPreferences
- `MainActivity` - главное окно с Navigation Drawer
- `LengthConverterFragment` - UI конвертера с RecyclerView

**Особенности реализации:**
- Использование RecyclerView для эффективного отображения большого списка
- ViewHolder pattern для оптимизации производительности
- TextWatcher для отслеживания изменений в полях ввода
- SharedPreferences для персистентного хранения

**Коэффициенты перевода:**
Все единицы переводятся через метр как базовую единицу СИ. Коэффициенты:
- 1 км = 1000 м
- 1 дм = 0.1 м
- 1 см = 0.01 м
- 1 мм = 0.001 м
- 1 фут = 0.3048 м
- 1 дюйм = 0.0254 м
- 1 ярд = 0.9144 м
- 1 миля = 1609.344 м
- 1 морская миля = 1852 м
- 1 световой год = 9.461E+15 м
- 1 астрономическая единица = 1.496E+11 м
